# 1.85 正式版操作与验证

- 点选：轻点后持续行进；长按约180ms或拖动8dp进入实时跟随，松手保留最后目标。停止清除所选队命令。跟随受实体墙阻挡，绕墙使用点选/画线。
- 分队：分兵后选A/B/C先后下令；合流集中队伍。画线模式松手后执行路线。路线被障碍阻断时重新规划/反馈，有限寻路与拥堵不能保证所有狭窄地形永不卡住。
- 据点：在对局设置选择据点玩法，进入范围争夺并显示进度；产液受真实核心人口/空间和周期限制，参与实际战斗。经典胜负保持。完整占领/结算规则见[规则](../operations-1.80/PLAY.md)。
- 限时道具：16类统一10秒，重复刷新不累加；暂停冻结时间，回溯清除效果。一次性道具仍为一次生效。
- 公网联机：在游戏内登录→快速匹配或好友房；最多6席，不足用电脑补齐；仅16种内置表情。邮箱验证、密码登录、设置密码及验证码重置均已接入。房主离开结束，没有房主迁移/战斗断线续局/中途加入。
- 分享游戏：系统分享面板选择已安装的微信/QQ等应用，发送动作由玩家完成。游戏链接指向浩科软件详情；房间邀请另含房间码与入口。交流群1136036532。
- 更新：主菜单前台自动检查；玩法说明底部可手动检查。已验证签名/身份/兼容性才显示有效发布；对局不检查，不自动下载安装；忽略和稍后保存到本机。
