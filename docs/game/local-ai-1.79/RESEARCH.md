# 开源方案核实与实际选用

核对日期：2026-11-08。固定提交及仓库元数据见 `research-projects.json`。许可证按仓库原文核对，不能只依赖 GitHub 的 SPDX 自动识别。

| 项目 | 核实结果与适配成本 | 本次处理 |
| --- | --- | --- |
| [Tencent/behaviac](https://github.com/Tencent/behaviac) | BSD-3-Clause 主许可，附带组件有 MIT/NCSA 等条款；C++/C# 行为树、状态机、HTN，支持 Android。编辑器、导出格式、运行时及旧构建说明需要额外适配；默认分支最近提交为 2022-07-06，不能说仍在活跃更新。 | 没有引入。框架负责组织行为，本游戏缺的是观察、战术评分和执行检查。 |
| [libgdx/gdx-ai](https://github.com/libgdx/gdx-ai) | Apache-2.0；Java 行为树、寻路、状态机；可不使用完整 libGDX 引擎，但仍需 libGDX core。默认分支最近提交为 2024-10-01。 | 没有引入。权威状态已有 C++ 网格，在 Java 重建同一套图和状态增加跨 JNI 复制与依赖。 |
| [Farama-Foundation/MicroRTS](https://github.com/Farama-Foundation/MicroRTS) | GPL-3.0；Java RTS 研究环境，含搜索/策略研究实现。README 于 2025-08-11 宣告停止维护；其离散单位规则和当前粒子核心不同。 | 仅作架构背景参考，不运行训练环境，不移植其规则或源码。 |

实际实现：新增自主编写的 `application/local_tactics.*`，沿用本项目网格、State 只读观察、现有合法触点和道具 nonce。采用局部态势评分、目标迟滞、通行图加权寻路、卡住检测和分队错峰规划。这些是通用算法方法，没有复制上述项目代码、没有新增运行依赖。新文件沿用 GPL-3.0-or-later。

旧 `AiTactics` 保留，既用于可复现的 1.78 对照，也避免改变模型队伍既有执行层。当前本地策略能看到己方、盟友、公开道具，以及 144 格内无遮挡且不隐身的敌军位置。基线旧 AI 有更广的敌军信息，报告中明确这一差别。

限制：这是一套有状态的启发式战术控制，不是训练完成的强化学习模型，也不宣称能理解所有战局。真正采用与未采用的项目应明确区分。
